# ADR-0006: i18n with a small typed dictionary

Status: accepted · 2026-09-26

## Context
The UI needs `en` and `ru` from day one (docs/06). `docs/06` suggested paraglide-js or svelte-i18n. The app has two
languages, a few hundred strings, and must build identically for Cloudflare and Node inside a monorepo whose type
checking runs through `tsc -b` and `svelte-check`.

## Decision
`apps/web/src/lib/i18n`: `en.ts` is the source of keys; `ru.ts` is typed as the same shape (a missing or extra key is a
type error). `translator(locale)` interpolates `{name}` parameters and picks plural forms with `Intl.PluralRules`
(`one/few/many/other`). The locale comes from the `vd_lang` cookie, else `Accept-Language`, resolved in
`hooks.server.ts` so server-rendered pages are already in the right language.

## Consequences
+ No code generation step, no extra build plugin; works the same in both adapters and in tests.
+ Keys and parameters are checked by TypeScript.
− No message extraction tooling or translator UI; fine for two languages maintained in the repo. Revisit
  (paraglide-js) if community translations arrive.
